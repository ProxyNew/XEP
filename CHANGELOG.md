# Changelog

## 1.0.0

Initial public release version of XEnchantmentPatcher.

- Creates enchanted variants of eligible weapons, armor and jewelry.
- Provides enchantment-origin selection, equipment review and output previews.
- Leaves leveled-list conflict resolution disabled by default; it is an explicit opt-in.
- Enables new material lists for specialized enchanted distribution by default.
- Supports compatible existing distribution routes and explicit specialized-distribution choices.
- Validates generated ESPFE output and supplies runtime companions when needed.
- Includes GPL-3.0-only licensing, third-party notices and corresponding-source packaging.

The public version series starts at 1.0.0. Earlier development build numbers are not public release versions.
